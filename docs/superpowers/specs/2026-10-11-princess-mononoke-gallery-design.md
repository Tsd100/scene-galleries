# 《幽灵公主》场景画廊设计

## 目标

在现有“场景漫游作品集”中增加一套可离线打开的《幽灵公主》主题画廊。作品使用新生成的非官方插画，延续《千与千寻》和《天空之城》项目的场景目录、画面热点、键盘翻页、自动巡游、全屏与移动端支持。

## 内容结构

画廊包含 16 个连续场景，每章 4 景：

1. **被诅咒的旅程**：虾夷村晨雾、灾祟来袭、出发西行、山谷初见。
2. **森林诸神**：古木密林、木灵溪谷、山犬巢穴、鹿神湖畔。
3. **铁镇冲突**：铁镇远眺、炼铁火场、城门对峙、夜袭林地。
4. **生命重生**：月下鹿神、山巅追逐、洪流过境、雨后新绿。

默认入口为“鹿神湖畔”。主线热点按 01 → 16 → 01 循环，在森林与铁镇节点增加返回或分支热点。

## 视觉设计

- 画面：16:9 横幅，1990 年代日本手绘赛璐璐动画背景质感，水彩背景、细腻线稿、自然光影和胶片颗粒。
- 色彩：森林使用湿润的苔绿、雾蓝和月白；铁镇使用炭黑、铁锈红和炉火橙；结尾过渡到清亮嫩绿。
- 人物与场面：以环境叙事为主，人物保持中远景，突出森林尺度、山犬与神兽的庄严、铁镇劳动感和人与自然冲突。
- 页面：深松绿底色、骨白文字、朱砂红强调色；环境粒子改为漂浮孢子与灰烬。
- 禁止：电影截图、片中文字、水印、现代物件、3D 渲染感、照片质感。

## 程序结构

- `princess-mononoke-gallery/scenes.js`：16 个场景及热点数据。
- `princess-mononoke-gallery/app.js`：复用经过验证的播放器逻辑。
- `princess-mononoke-gallery/index.html`：画廊结构与初始场景。
- `princess-mononoke-gallery/style.css`：独立主题。
- `princess-mononoke-gallery/assets/`：WebP 主图和缩略图。
- `princess-mononoke-gallery/tests/scene-data.test.cjs`：场景数量、图片存在、热点有效性测试。

## 验收

- 16 张主图与 16 张缩略图均能本地读取。
- 16 个场景 ID 唯一、四章各四景、所有热点目标存在。
- 键盘、目录、自动巡游、全屏、减少动态效果和移动端入口工作正常。
- 根目录首页、README 和素材声明同步更新。
- 代码与原创生成素材通过 Git 检查后提交并推送到公开仓库。
